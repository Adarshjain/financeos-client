# Logo

The FinanceOS mark: a ₹ on a `brand` rounded square, optionally followed by the wordmark "FinanceOS". Used by Rail, TopBar, and the sign-in, sign-up and offline pages.

## Props
- `variant`: `'mark' | 'full'` (default `'mark'`)
- `size`: `'sm' | 'md'` (default `'md'`)
- `symbol`: `string` (default `'₹'`)

## Variants
- `mark`: the square alone. `sm` 28px or `md` 32px.
- `full`: mark plus "FinanceOS" wordmark in 800.
