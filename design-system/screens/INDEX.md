# Screen index

Every board of the FinanceOS redesign canvas (https://claude.ai/artifact/2nScEY5nAvHeKduXKSTAoG), copied here so any tool can read it.

- `*.dc.html` open in a browser (they load `support.js` next to them). `D-` = desktop (1440 wide), `P-` = phone (390 wide), `ds-` = design-system pages.
- `shots/*.webp` = screenshots of the same boards, for tools that read images.
- Boards named `*-states` are phone state sheets: several states of one area side by side.
