Each component with its rules, rendered in the light and the dark theme.

Card
Data display

The container for a group of related rows: a header with title, subtitle and an optional link or small action, then rows separated by `line-soft`.

Use

  • Header: ct title (14px, 800), cs subtitle in ink-3, link at the right ("Inbox ›").
  • Cards have a line border and radius-lg, no shadow.
  • Cards sit on bg-canvas; never nest a card in a card (use a section band or note instead).
  • The list's Pager, when it has one, is the card's last row.

Variants

  • Title with subtitle and link, with an action, with rows, with a pager footer, with section bands, empty.

ListRow
Data display

Rows inside cards. `row` is a flexible line (leading badge or avatar, text block that grows, trailing value or action). `fld` is a label/value pair for detail sheets.

Use

  • Primary line body-strong, secondary line cs in ink-3.
  • Trailing amounts are right-aligned, tabular, 700 weight; credits are positive with a + sign.
  • Detail sheets list facts as fld rows: label in ink-3 on the left, value on the right.
  • Highlighted (hl): a row opened from a notification scrolls into view with a 2px brand outline on brand-tint.

Variants

  • Leading: badge, date tile, avatar, icon tile or nothing. Trailing: action, amount, chevron, kebab. Plus highlighted, label/value and disabled rows.

TransactionRow
Data display

The phone transaction row: merchant and amount on top, a context line and category below. Status is told with coloured words, not tags.

Anatomy

  • Line 1: description (heading) · amount (700, tabular, credits positive with +). Running balance sits under the amount in caption.
  • Line 2, the context line, in this order: account name first, plastic (••7741), then amber review words, a note, blue link/record words, then grey provenance.
  • Right of line 2: the first category chip, plus a "+n" chip if there are more. A dashed amber "Set category" chip when none is set.

Word colours

  • Amber (warning, 700): needs you. Review reasons (Unreconciled, Category unverified, Duplicate, Date corrected) and Watching.
  • Blue (info, 600): connected to something. Links show a small chain glyph (⛓ Transfer out, Refund); records show none (EMI #8 · HDFC car loan, Lending · Priya Nair, Dividend · INFY).
  • Grey (ink-3): provenance. Gmail, Statement, Manual, Excluded.
  • Green: credit amounts only.

States

Selected (brand-tint with a 3px brand stripe), monitored (watch-tint with a 3px watch stripe), excluded (60% opacity), selection mode (trailing eye icon opens the detail).

Don't

  • No tags or pills for status on the row. No date on the row on phone: the sticky date header carries it.

Widget
Data display

A dashboard tile: title, subtitle and a ⋮ menu, then a figure, rows, a chart or a table. Widgets size to their content.

States

  • Loading: a skeleton in the widget's own shape (a figure or rows).
  • Failed: an inline error with Retry; the rest of the dashboard still renders.
  • Unavailable: the report behind it was deleted; offer Remove.
  • Report tables sort by header and page inside the widget.

⋮ menu

Report widgets: Edit report · View full page · View underlying data (KPIs). Built-ins and templates: Widget settings · Duplicate as my report (templates) · View full page.

KpiTile
Data display

A single figure with its label and what changed. Home leads with Net worth in the hero size; other tiles use `figure`.

Anatomy

Overline label (lbl), value (kv, tabular; kv-hero for the one headline number), a delta line (▲/▼ with positive or danger plus words like "vs Sep"), then optional context: a progress bar, two small badges, or a breakdown line.

Use

  • Two columns on phone, three or four on desktop.
  • A rise in spending is danger, a rise in net worth positive: colour follows good or bad, not up or down.

Variants

  • Hero, delta in the bad direction, with a bar, with badges, loading, failed.

Badge
Data display

A small coloured label for a state that applies to a whole item (a bill, a job, a statement), never on transaction rows.

Tones

b-green done or paid · b-amber due soon, warning · b-rose missing, failed, overdue · b-blue informational counts and sources · b-grey neutral.

Copy

One or two words, sentence case, no punctuation: "Paid", "2 days", "Missing", "1 warning".

Variants

  • Five tones; the sets used for statement verdicts, bill due states and account states.

CategoryChip
Data display

The category on a transaction or rule: a soft pill in `bg-subtle`.

Variants

  • cat: one category.
  • cat cat-n: "+2" when there are more than fit; the rest show in the detail sheet.
  • cat cat-set: dashed amber "Set category" when none is set; tapping it opens the picker.

StatusWords
Data display

Inline coloured words on a context line that tell state without tags. Shared by transaction rows, rule cards and detail sheets.

Vocabulary

  • rv amber 700: needs you. Unreconciled · Category unverified · Duplicate · Date corrected · Watching · Unverified.
  • lk blue 600: linked or recorded elsewhere. Links get the 10px chain glyph.
  • pv grey: where it came from. Gmail · Statement · Manual · LLM-generated · Created by you · Excluded.
  • Green 700 "Verified" on rules.

Rule

A word, a middle dot (·) between words, never a pill. Colour is never the only signal: the word itself says it.

RuleCard
Data display

A record card for lists where each item has several facts and actions (categorisation rules). Grid of three on desktop, one column on phone.

Anatomy

  • Header: name (rt) with "match type · pattern" under it; the used count alone at the top right.
  • Status line: status word (amber Unverified or green Verified) · source · MCC.
  • Bottom row: category chips, then Approve (unverified only) and ⋮ (Find matches · Edit rule · Delete rule).

Selection mode (phone)

Long-press starts it. Selected cards turn brand-tint with a brand outline; on every card the eye icon replaces Approve and ⋮ and opens the edit sheet.

Variants

  • Unverified (with Approve), selected, verified (⋮ only), and a card in selection mode that is not selected (eye only).

Avatar
Data display

Identity marks: rounded-square initials for accounts and banks, circles for people.

Use

  • Accounts and institutions: av 32px rounded square, or the bank's real logo at 22px inside lists and pickers.
  • People (lending counterparties, profile): avr 30px circle in brand-tint with initials.
  • Never draw a bank's mark yourself; use the fetched logo or initials.

SectionBand
Data display

Form sections inside sheets are full-width grey bands with an uppercase caption, not cards.

Use

  • sec band: overline caption in ink-4 on bg-sunken, bleeding to the sheet edges. Fields follow below it.
  • Used on Add and Edit account (Basics · Card details · Limit · Sync & net worth) and Edit transaction (Reward details). Destructive sections (Delete account) use danger text.

Variants

  • Default band, and the danger band that closes an edit sheet.
