# Foundations

Design system tokens and foundations rendered as a Storybook MDX docs page (`Foundations.mdx`).

## What it does
Documents the design system tokens loaded directly from `tokens.json`: colours (grounds, lines, ink, brand, status, series), typography styles, spacing steps, radii, and shadows.

## Props
None (documentation page).

## Built from
Tokens (`tokens.json`, `tokens.css`).

## Variants
- MDX documentation page.
