# DateGroupHeader

The sticky header above each day's rows on phone lists: "12 Oct" in 800 with the weekday in `ink-3`.

## Use
- Sticks to the top while its rows scroll (`z-sticky`). `bg-subtle` ground so it reads as a band, not a row.
- Desktop tables keep a Date column and use a month band instead ("September 2026 · 61 transactions · out ₹1,05,219", `overline`).
