# Logo

The FinanceOS mark: a ₹ on a `brand` rounded square, optionally followed by the wordmark "FinanceOS". One component used by AppBar, Rail and the sign-in, sign-up and offline pages, so the mark is drawn once.

## Variants
- `mark`: the square alone. `sm` 28px (`chip`, Rail and AppBar) or `md` 32px (`control-md`, auth pages).
- `full`: mark plus "FinanceOS" in 800.

## Built from
Nothing else (tokens only).
