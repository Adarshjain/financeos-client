# AuthPanel

Login and sign-up: an illustrated mint panel (on phone a short strip on top) and a narrow form column, max 380px.

## Anatomy
- Panel: `illus-mint` ground with floating tiles (`radius-xl`, `shadow-raise`), a brand card and a gold coin. Shapes only; no stock photos.
- Form: `screen-title` headline, one line of copy, "Continue with Google" (`gbtn`, 44px), an "or" divider, email and password, primary button full width.
- Sign-up adds an invite code field and a three-step explainer.
