# Divider

A 1px `line` rule, optionally with a short centred label in `ink-4` caption ("or" between Continue with Google and the email form).

## Props
- `label?: React.ReactNode`: optional short centred label (can also be passed as children).
- Plus native `<div>` attributes and ref forwarded to the root element (`role="separator"`, `aria-orientation="horizontal"`).

## Variants
- Plain, with label.

## Built from
Nothing else.
