# ListField

A label/value pair for detail sheets.

## Props
- `label`: `ReactNode` (the left-aligned label)
- `value?: ReactNode` (the right-aligned value)
- `borderTop?: boolean` (whether to show top divider; default `true`, with `first:border-t-0`)

## Built from
Nothing else.

## Variants
- Default, withTopBorder.
