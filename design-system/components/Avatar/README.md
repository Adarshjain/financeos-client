# Avatar

Identity marks: rounded-square initials for accounts and banks, circles for people.

## Use
- Accounts and institutions: `av` 32px rounded square, or the bank's real logo at 22px inside lists and pickers.
- People (lending counterparties, profile): `avr` 30px circle in `brand-tint` with initials.
- Never draw a bank's mark yourself; use the fetched logo or initials.
