41Idempotency matrix and concurrency analysis

Executive summary

Automated ingestion is idempotent by design (unique keys on message id, file hash and source message id). Manual creates are not (no idempotency keys anywhere). Reads are pure. No entity in the codebase carries @Version, so every concurrent edit is last-write-wins and every check-then-act race falls through to a database constraint error rather than a clean 409 with a friendly message. The single job worker and single VM mean scheduled work never duplicates. Confirmed

43Reconciliation, correctness and auditability

Executive summary

FinanceOS has exactly one built-in reconciliation mechanism between two independent sources, Gmail alerts against statement lines, plus a few advisory signals (bank reconciliation gap badge, statement checksum verdict, broker realized cross-check, holdings snapshot DATA_GAP). There is no job that checks derived numbers against anything, no correction workflow beyond edit and merge, and no audit trail outside single-transaction mutations. Because derived figures are recomputed from source facts, the practical question "how would we know FinanceOS is wrong" reduces to "how would we know the facts are wrong or the formula is wrong". Confirmed

Scenario 7: Boundary and unexpected states

  • Zero amount: manual create rejected (400); ingestion cannot insert 0 (CHECK > 0).
  • Negative amount: form accepts a signed input and converts to DEBIT; server stores abs.
  • Transaction dated in the future: accepted; counted in balances and rewards by effective date.
  • Same statement to two accounts of one user: allowed (sha256 unique per account).
  • Closed account receives a Gmail alert: created normally; closure only blocks card mutations.
  • Delete an account: transactions cascade; statements cascade; Gmail ledger rows cascade (so a re-created account re-ingests); jobs remain.
  • Delete a user mid-sync: 409 ACCOUNT_DELETE_BUSY after a 5 s drain.
  • Two tabs edit the same loan: last write wins, no conflict.
  • Anniversary date Feb 29: clamped to Feb 28 in non-leap years.
  • Reward rule with tiers JSON corrupted: rule skipped with a log warning; transactions earn NO_RULE or fall to the next rule.
  • Report KPI on a computed datasource with comparison.enabled null: NullPointerException → 500.
  • Gmail primary connection disconnected: manual sync 404s even with another live connection.
